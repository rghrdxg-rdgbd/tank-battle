# 坦克大战 · Tank Battle

一个纯 HTML5 Canvas 实现的经典「坦克大战（Battle City）」小游戏，单个文件即可运行，无需任何依赖或构建工具。

## 在线试玩

通过 GitHub Pages 访问：`https://<你的用户名>.github.io/tank-battle/`

（也可以直接用浏览器打开 `index.html` 本地游玩。）

## 玩法

- 控制你的黄色坦克，**保护基地的金色老鹰**不被击毁
- 消灭每一关刷出的所有敌方坦克即可过关，关卡会不断循环、难度递增

## 操作

| 按键 | 作用 |
| --- | --- |
| `方向键` / `WASD` | 移动坦克 |
| `空格` / `J` | 开火（长按连发） |
| `P` / `Esc` | 暂停 / 继续 |
| `Enter` | 开始 / 重新开始 |

触屏设备上会自动显示虚拟方向键与开火按钮。

## 特性

- 4 种敌方坦克：普通、快速、重型（3 血）、特殊（掉落道具）
- 可破坏的砖墙、不可破坏的钢铁、坦克无法通过的水面
- 道具系统：★ 火力升级、▲ 无敌护盾、● 全屏轰炸、♥ 额外生命
- 音效（Web Audio 合成，无需音频文件）
- 计分、生命、关卡、最高分本地存档
- 出生保护、爆炸粒子、屏幕震动、暂停等功能

## 技术说明

- 单文件 `index.html`，原生 JavaScript + Canvas 2D，无任何外部依赖
- 通过 `requestAnimationFrame` 驱动、按时间步长更新，兼容不同刷新率
- 直接双击打开或部署到任意静态托管（GitHub Pages / Vercel / Netlify 等）即可运行
